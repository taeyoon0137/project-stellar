# QA2 편집 확인 목록

샘플 프로젝트를 고치고 저장하는 동작을 확인합니다. 진행 방식과 피드백 형식은 [README](README.md)를 따릅니다.

- 실행: `./scripts/macos/qa.sh --fresh`(편집 QA는 깨끗한 샘플에서 시작합니다)
- 기준 명세: [도구·메뉴](../design/ui/tools_menus.md), [사이드바](../design/ui/sidebar.md) 4장, [인스펙터](../design/ui/inspector.md) 6장, [macOS 셸 디자인 가이드](../design/macos-shell-design.md) 2.5·5.2·8장
- 지금 빌드에는 셸에서 문서를 바꾸는 코어 경로가 없어 이 단계는 거의 모두 **구현 대기**입니다. 지금 확인할 수 있는 것은 편집 메뉴가 숨지 않고 비활성인지(QA0-38)와 텍스트 필드의 네이티브 편집(QA0-43)뿐입니다.
- 편집 확인이 가능해지면 각 항목 뒤에 `git -C <샘플 폴더> status --short`로 저장 결과도 확인합니다.
